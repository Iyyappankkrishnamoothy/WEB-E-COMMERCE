# 🛒 Web--E-commerce

A full-stack **E-Commerce Web Application** developed as part of the **Thiranex Internship Program**. This project demonstrates the implementation of an online shopping platform with user authentication, product management, shopping cart functionality, and order tracking using modern web technologies.

---

## 📌 Project Overview

The E-Commerce Web Application enables users to browse products, manage their shopping cart, place orders, and track their purchases. An administrator can manage products and monitor customer orders through a dedicated admin panel.

This project focuses on practical implementation of CRUD operations, REST APIs, authentication, and frontend-backend integration.

---

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/ecommerce.git
```

### Navigate to the Project

```bash
cd ecommerce
```

### Install Dependencies

```bash
npm install
```

### Start the Server

```bash
npm start
```

### Open the Application

```
http://localhost:3000
```

## 📖 Application Workflow

1. Register a new user account.
2. Login using your credentials.
3. Browse available products.
4. Search or filter products by category.
5. Add products to the shopping cart.
6. Update quantities or remove items.
7. Complete the checkout process.
8. Track previous orders.
9. Admin users can manage products and monitor orders.
